# 투표는 총알보다 강하다

2026년 더불어민주당 정기전국당원대회 후보의 **공개 발언을 이슈별로 확인 상태만 비교**하는 정적 기록입니다.

## 범위

- 후보별 공개 인용과 원문 링크를 제공합니다.
- 찬반 점수, 지지율, 계파, 동기, 영향력, 정책 효과를 평가하지 않습니다.
- `확인 자료 없음`은 자료 탐색 범위에서 직접 발언을 찾지 못했다는 뜻이며, 입장이 없다는 뜻이 아닙니다.
- 유시민 발언은 사안을 고르는 관점으로만 사용합니다. 영상 속 인과 해석이나 주장 자체를 사실로 확정하지 않습니다.

## 출처·보존 경계

이 공개 저장소에는 제3자 뉴스 원문 HTML, 원문 스크린샷, 수집 당시의 연락처나 개인정보를 포함하지 않습니다. 화면의 짧은 인용은 각 항목에 연결한 원문·보도 링크에서 확인할 수 있으며, 출처의 정정·삭제·수정 가능성은 별도로 존재합니다.

로컬 검증용 원문 자료는 이 공개 배포본과 분리해 보관합니다.

### 수집 카드 원문 검증

`showcaseRecords`에 추가하는 모든 카드의 직접 인용은 연결한 원문 본문에 실제 존재해야 합니다. 배포 전 아래 명령으로 데이터 검증과 원문 대조를 함께 실행합니다.

```bash
node --check app.js
node --check data/convention.js
node scripts/verify-showcase-records.mjs
```

검증 스크립트는 공개 카드의 원문 HTML을 저장하거나 배포 artifact에 포함하지 않고, 실행 시 원문을 요청해 인용문 포함 여부만 확인합니다. 일부 원문 사이트가 쿠키 기반 리다이렉트를 요구하는 경우에는 시스템 `curl`을 일회성 쿠키 저장소와 함께 대체 경로로 사용하며, 실행 후 해당 임시 자료를 삭제합니다.
